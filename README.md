站点域名：agmc.de5.cd

## 网站介绍
本网站是 AuroraGalaxy（极光星系）Minecraft互通服务器官方展示站点，面向所有玩家开放访问，用于展示服务器全部公开信息。

## 网站功能说明
1. **服务器宣传展示**
    - 轮播大图展示游戏内实景截图，直观展示服务器世界环境；
    - 内嵌B站官方宣传视频，快速了解服务器玩法与特色。
2. **服务器基础信息公示**
    - 服务器连接IP、游戏版本、Java/基岩互通说明；
    - 实时在线玩家数量查询；
    - 服务器特色、社区氛围、零氪公益机制介绍。
3. **新手进服指引**
    完整图文文字教程，区分Java版、基岩版玩家，包含客户端安装、进服步骤、网络问题解决方案。
4. **公告与注意事项**
    标注进服硬性要求、客户端加载器规范、服务器游玩规则。
5. **玩家留言板块**
    玩家可提交留言，分享游玩体验、提出建议与问题。
6. **简易玩家账号系统**
    支持玩家自主注册、登录账号，用于后续社区配套功能拓展。
7. **导航链接**
    内置服务器Wiki、社区文档等配套站点快捷跳转入口。
